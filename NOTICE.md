This release matches tracker-ff 1.2.0 (tag `tracker-ff-v1.2.0`, commit 9ef9dc5) and plays its 18 synth engines: the six built in (ACD, FAT, VAP, WTFM, PERC, CHIP), the ten OpenTracker 3.x engines and the two FF-engines PHZ and PLK (Pluck 1.1). It contains and links code from other projects. The licence texts are in `LICENSE`, `vendor/poly/LICENSE-*`, `vendor/ot3/LICENSE-*`, `host/sdk/LICENSE-*`, the file headers named below and the `LICENSE*` files that come with each module set (`bun run modules` puts them in `build/modules/<set>/`).

## Runtime modules (not in this repository)

The editor loads these WebAssembly modules at run time. `modules.lock.json` pins each set by repository, tag and sha256, the same releases tracker-ff 1.2.0 pins. Each set ships its own `NOTICE.md` and licence texts, which the editor serves next to the modules.

| Set | Modules | Source | Licence |
|---|---|---|---|
| `engines-os` | the ten OpenTracker 3.x engines above | `sbialy/tracker-engines-os` v1.2.0 (public, published release) | MIT (`LICENSE-OpenTracker-synths-MIT.txt`), Apache-2.0 for the OpenTracker headers (`LICENSE-OpenTracker-Apache-2.0.txt`), the plugin runtime of tracker-ff (`LICENSE-tracker-ff-MIT.txt`, `LICENSE-PolyendTracker-CE.txt`) |
| `effects-os` | master inserts Dirt, Tape, Lo-Fi, BBD, Phaser, ports of opentracker-fx (https://github.com/opentracker-fw/opentracker-fx) | `sbialy/tracker-effects-os` v1.2.0 (public, published release) | MIT, Copyright (c) 2026 Marcin Spoczynski (`LICENSE-OpenTracker-fx-MIT.txt`), Apache-2.0 for the OpenTracker DSP headers BBD and Phaser use (`LICENSE-OpenTracker-Apache-2.0.txt`) |
| `engines` | PHZ and PLK (Pluck 1.1), clean-room engines of this project. PHZ is written from the public Polyend Synth manual and its voice skeleton follows OpenTracker's VAP engine. No Mutable Instruments code | published as a GitHub release by the author (tag engines-v1.2.0, PLK 1.1 from a later commit), binary modules only | proprietary freeware (`LICENSE.md` of the set, the final wording is `docs/LICENSE-ff-modules.md`): free use with the Tracker, tracker-ff and this editor, unmodified redistribution, no modification or sale. Apache-2.0 for the PHZ parts that follow VAP (`LICENSE-OpenTracker-Apache-2.0.txt`). The PHZ source published in the tracker-ff releases up to 1.1.0 keeps the licence of those releases |
| `effects` | master inserts Console and Tube, own designs | published as a GitHub release by the author (tag effects-v1.0.0), binary modules only | proprietary freeware (`LICENSE.md` of the set), the plugin runtime of tracker-ff stays MIT (`LICENSE-tracker-ff-MIT.txt`) |

Without the `engines` and `effects` sets the editor still runs every other engine and insert.
